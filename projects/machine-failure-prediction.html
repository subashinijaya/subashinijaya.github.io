Machine Failure Prediction

A classification model predicting machine failure risk from sensor data, built for MDA512 (Data Science) as a group project.

Python Classification Group project

01 Business problem

Unplanned machine failure disrupts industrial operations. The project's goal was to develop a model that flags failure risk early enough to support proactive intervention rather than reactive repair.

02 Background & dataset

Custom machine sensor dataset.

  • Features: Temperature, Vibration, Power Usage, Humidity, Machine Type
  • Target variable: Failure_Risk (1 = failure likely, 0 = no failure)

03 My role

This was a group assignment for the MDA512 Data Science unit (Group 3). I contributed to the data preparation and modelling work alongside my teammates.

04 Tools & technologies

PythonLogistic Regression Decision TreeRandom ForestGradient Boosting

05 Methodology

Four classification models were trained and compared on the sensor dataset:

  • Logistic Regression
  • Decision Tree Classifier
  • Random Forest
  • Gradient Boosting

06 Key insights

Gradient Boosting performed best, with the highest F1-score and lowest misclassification rate among the four models tested.

07 Deliverables

  • Jupyter notebook with the full analysis
  • Final written report (DOCX and HTML)
  • Group presentation slides

08 What I learned

Comparing multiple classification algorithms on the same dataset made the trade-offs between interpretable models (Logistic Regression) and higher-performing ensemble methods (Gradient Boosting) concrete rather than theoretical.
