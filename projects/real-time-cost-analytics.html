Real-Time Data Visualisation & Cost Analytics

An interactive Streamlit web app for energy cost monitoring — live-updating charts, KPI metrics and multi-country comparison across a 25-year global energy dataset.

Python Streamlit Pandas

01 Business problem

Teams without a Power BI or Tableau licence still need interactive, browser-based analytics — and operational monitoring often needs to feel live, not just periodically refreshed.

02 Background & dataset

Global energy consumption dataset covering 10 countries over 2000–2024.

  • 10 countries, 25 years of yearly data

03 Objectives

  • Provide an interactive, browser-based analytics dashboard without BI licensing
  • Monitor energy consumption and price trends across countries and years
  • Demonstrate real-time data streaming and incremental chart updates
  • Showcase full-stack data app development in pure Python

04 Tools & technologies

Python 3StreamlitpandasNumPy

05 Data cleaning & preparation

Data loaded with Streamlit caching (@st.cache_data), then cleaned by aggregating duplicate country-year rows via a pandas groupby.

06 Methodology

  • KPI metric cards — total consumption, average price, renewable share, carbon emissions
  • Interactive filters — multi-select country picker and year range slider
  • Trend charts — consumption and price by country over time
  • Comparison charts — renewable share vs fossil dependency
  • A simulated real-time price feed with incremental chart updates and delta metrics
  • An expandable, filterable data explorer table

07 Dashboard & visualisations

Dashboard overview — KPI cards and trend charts
Live cost monitor — simulated real-time price feed with delta metrics

08 Key insights

  • A fully interactive analytics app can be built and deployed with pure Python, no BI licence required
  • Streamlit's caching and session model made the real-time feed simulation feel genuinely live
  • pandas groupby/pivot patterns were essential to keep chart data clean despite duplicate rows in the source

09 Challenges & limitations

The dataset is yearly and country-level. The "live feed" section simulates real-time price ticks around the historical average to demonstrate streaming visualisation patterns — in production this would connect to a live API or message queue such as Kafka or MQTT.

10 What I learned

  • Streamlit app architecture — layout, caching, session interactivity
  • Real-time visualisation patterns using placeholders and incremental rendering
  • Building deployable data apps in pure Python, beyond traditional BI tools
